# 本地媒体中心 · 安装说明

这份说明写给**不写代码的人**。想了解项目概况与运行方式请读仓库里的 `README.md`。

---

## 这是什么

把你自己电脑上的照片和视频，变成手机上随时能翻的相册 + 影院。

服务端跑在你自己的一台电脑上（Windows / macOS / Linux 都行），手机通过**同一个 Wi-Fi**
连过去看图、看视频。**所有数据都在你自己的局域网里，不经过任何云端服务，也不需要联网。**

---

## 你拿到的是什么

解压后应该看到：

```
mediacenter-<版本>-<系统>-<架构>/
├── mediacenter          ← 服务端程序（Windows 上是 mediacenter.exe）
├── INSTALL.md           ← 就是这份说明
└── service/             ← 想让它开机自动运行，用这里的脚本
    ├── install.sh  /  install.cmd
    └── uninstall.sh  /  uninstall.cmd
```

手机端是**另一个文件**（`MediaCenter.apk`），单独装到手机上。

---

## 第一步：启动服务端

**macOS / Linux** —— 打开「终端」，进到解压出来的目录，运行：

```bash
./mediacenter
```

macOS 首次运行可能提示"无法验证开发者"，到「系统设置 → 隐私与安全性」里点「仍要打开」。

**Windows** —— 直接双击 `mediacenter.exe`。

启动后会打印这样一段：

```
MediaCenter-你的电脑名 v0.1.0
  数据目录 : /Users/you/.mediacenter
  本机访问 : http://localhost:8080/?token=3f2a9c...
  局域网   : http://192.168.1.23:8080/?token=3f2a9c...
  访问令牌 : 3f2a9c...
```

**把这一段留着，下一步要用**，尤其是那串 token。

> 这个窗口要一直开着 —— 关掉服务就停了。想让它开机自动跑，见下面「让它开机自启」。

---

## 第二步：连接手机

打开手机上的「本地媒体中心」，在连接页粘贴上一步的**局域网**地址（连 `?token=` 一起）。

如果手机和电脑在同一个 Wi-Fi 下，通常会**自动发现**，直接点列表里的服务器就行，不用手输。

连上后能看到统计数字（照片 N / 视频 N）。如果都是 0，看下面「为什么是空的」。

---

## 第三步：告诉它你的照片在哪

服务端**不会自动去翻你的整个硬盘**，你得明确指定要索引哪些目录。

1. 客户端进入「图库」页
2. 点右上角**带滑杆的图标**（服务器管理）
3. 「媒体目录」→ 点「添加」→ 填目录的完整路径

例如 `~/Pictures`、`D:\照片`、`/Volumes/外置硬盘/相册`。填完会自动开始扫描。

> **服务端和你的照片在同一台机器上**，所以这里填的是**那台机器上**的路径，
> 不是手机上的路径。

---

## 让它开机自启（可选）

**macOS / Linux**：

```bash
./service/install.sh
```

**Windows**：运行 `service\install.cmd`（普通用户即可，不需要管理员）

卸载用同目录的 `uninstall.sh` / `uninstall.cmd`。

> **卸载自启、甚至直接删掉程序，都不会动你的照片和索引** —— 它们都在数据目录里（见下）。

---

## 你的东西放在哪

| 内容 | 位置 |
|:---|:---|
| 配置（含访问令牌） | `~/.mediacenter/config.json` |
| 索引数据库 | `~/.mediacenter/index.db` |
| 缩略图缓存 | `~/.mediacenter/thumbs/` |
| 手机备份上来的照片 | `~/.mediacenter/library/` |
| 开机自启后的日志 | `~/.mediacenter/logs/` |

（Windows 上 `~` 指 `C:\Users\你的用户名`）

**要备份就备份 `~/.mediacenter` 整个目录。** 删掉它等于丢掉索引和手机备份上来的照片；
你手动添加的那些原始照片目录不受影响。

## 常见问题

### 为什么是空的 / 照片不全

- 还没添加媒体目录 → 见第三步
- 刚添加完 → 首次扫描需要时间，大目录可能几分钟到几十分钟
- 手机上看到的是旧数据 → 下拉刷新

### 端口 8080 被占用了

启动会**直接报错退出**，不会偷偷换端口（否则你会找不到服务在哪）。改
`~/.mediacenter/config.json` 里的 `port`，比如改成 8090，重启即可。客户端那边记得用新端口。

### 视频没有缩略图

需要 `ffmpeg`。没装也能播放视频，只是没有缩略图和详细元数据。

- macOS：`brew install ffmpeg`
- Linux：用发行版的包管理器装 `ffmpeg`
- Windows：到 ffmpeg 官网下载，把 `ffmpeg.exe` 所在目录加进 PATH

装完重启服务端。启动横幅里不再出现"未检测到 ffmpeg"就是认到了。

> 如果**手动运行能找到 ffmpeg、开机自启后却找不到**：自启服务的 PATH 比终端精简得多。
> 自启脚本里已经补上了 Homebrew 的常见位置（`/opt/homebrew/bin`、`/usr/local/bin`）；
> 如果 ffmpeg 装在别处，在 `config.json` 里把 `ffmpeg_path` / `ffprobe_path`
> 写成**绝对路径**最稳妥。

### 手机连不上

- 确认手机和电脑在**同一个 Wi-Fi**（不是手机流量、不是访客网络）
- 电脑防火墙可能拦了 8080：Windows 首次运行会弹窗询问，选「允许访问」；
  macOS 在「系统设置 → 网络 → 防火墙」里放行
- 路由器开了「AP 隔离」（也叫客户端隔离）会让设备互相看不见，需要在路由器设置里关掉
- 确认粘贴的地址里 `token=` 没被截断

### 换台电脑 / 升级版本

把新的程序覆盖旧的，重启即可。索引和配置都在 `~/.mediacenter`，不受影响。

> **如果你装过更早的测试版手机 App**：它的签名和现在的正式版不同，系统会拒绝覆盖安装，
> 需要先卸载旧版再装新版。这是一次性的，之后都能正常升级。

---

## 一点安全说明

- 服务端只在**局域网**里监听，路由器外访问不到
- 访问需要那串 token，所以别把带 token 的地址发到公开的地方
- 换 token 的办法：删掉 `~/.mediacenter/config.json` 里的 `token` 字段，重启会自动生成新的
